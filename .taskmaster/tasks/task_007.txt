# Task ID: 7
# Title: Implement Full-Text Search with MeiliSearch
# Status: pending
# Dependencies: 4
# Priority: medium
# Description: Integrate MeiliSearch to provide fast, full-text search over user content, using an asynchronous indexing strategy.
# Details:
Implement the Outbox Pattern: create an `OutboxEvent` table to log content changes (create, update, delete). A scheduled background job will process these events, updating the MeiliSearch index accordingly. Configure the MeiliSearch index with appropriate searchable and filterable attributes (e.g., title, body, tags, categoryId). Implement the `/api/search` endpoint to query MeiliSearch, ensuring results are filtered by the authenticated user's ID.

# Test Strategy:
Create, update, and delete content and verify the changes are reflected in the MeiliSearch index after a short delay. Test the search API with various keywords and filters (by category, by tag). Confirm that a user's search query only returns their own content. Test partial word matching.
