# Task ID: 9
# Title: Implement User Statistics & Analytics Aggregation
# Status: pending
# Dependencies: 4, 5
# Priority: low
# Description: Build a system to aggregate and expose user activity statistics for visualization in the front-end.
# Details:
Create a scheduled job (daily at 02:00 KST) to process the previous day's activity. Aggregate metrics like new content created and total content count. Store these daily aggregates in a dedicated statistics table. Implement API endpoints (`/api/stats/...`) to provide this data aggregated by day, week, and month. Ensure all date-based calculations correctly use the KST timezone.

# Test Strategy:
Manually add content on different days. Trigger the aggregation job and verify that the statistics table is populated correctly. Call the stats API for daily, weekly, and monthly ranges and check if the returned data is accurate and properly formatted for charting.
